# 管理後台與匯入指南

管理後台：<https://jjfishjj.github.io/phonetic-star-planet-custom/admin/>。

## 帳戶與編輯

使用已建立且已授權的管理員帳戶登入。本專案不開放公開註冊；新增 Supabase Auth 帳戶不代表取得管理員權限，管理權限由資料庫中的 `phonetic_admins` 名單判斷。

牌組可編輯名稱、原文名稱、圖示、朗讀語言代碼、區域、排序及發布狀態。更改語言若會讓現有程度標註失效，資料庫會拒絕變更，避免資料被默默重新分類。

詞卡可搜尋、編輯單字、音標、諧音、中文意思、記憶畫面、四種 VARK 提示、主題、程度、原文例句、繁中翻譯、排序及發布狀態，並可依主題和程度篩選。例句與翻譯必須成對提供或成對留白；舊檔及尚未補例句的自訂資料仍相容。編輯 CEFR／JLPT／TOPIK 程度不會改寫原本 `difficulty`；其他語言沿用原有 1–3 難度。

「取消發布」只會隱藏雲端公開內容，不會刪除資料或識別。發布切換會保留程度、例句及主題資料。儲存後，前台在下次載入時同步已發布內容，不必重新部署 GitHub Pages。

## 匯出與匯入

選定牌組後可匯出 XLSX 或 UTF-8 CSV，也可下載該語言的空白 XLSX 範本。CSV 會帶 UTF-8 BOM，方便 Excel 顯示繁中。支援 `.xlsx`、`.xls`、`.csv`，只讀第一個工作表；每檔最多 5 MB、2,000 筆資料（不含標題列）。介面先預覽前 20 列及錯誤；有錯誤便不能匯入。確認後只呼叫一次原子匯入 RPC，任一列失敗就整批回滾。第一次建議先用 2–3 筆試匯入。

管理後台提供八份已填好的進階詞卡 CSV。正式站已具備全部 376 張進階卡，**不要再次用追加模式匯入這些 CSV**。編修現有卡前先匯出，保留卡片 `id` 與發布狀態，再使用更新模式。進階內容的編修來源為 `content/advanced/<語言代碼>.json`；修改後依[開發文件](DEVELOPMENT.md)重新產生前台資料與 CSV。

### 追加與更新規則

追加模式遇到同牌組既有單字或識別會報衝突。更新模式有 `id` 時依識別比對；沒有 `id` 時以同牌組完全相同的單字比對，找不到才新增。要改既有單字，建議直接在後台編輯。

更新時，省略或留白的 `published`、`position`、`topic`、`difficulty`、`proficiency_level` 會保留原值。省略 `roman`、`cue` 或任何 VARK 欄位也會保留原值；若檔案有該欄表頭而儲存格明確留白，則清空該欄。沒有例句欄位時保留原例句；同時提供兩個空白例句欄位則清除例句與翻譯。匯入介面要求原文及翻譯成對，資料庫 RPC 也會在套用省略值後檢查最終結果。

批次修改前建議匯出牌組並保留 `id`。管理端不能更新既有識別、`deck_id` 或 `legacy_index`。XLSX 以文字儲存匯入內容；CSV 會為類似公式的儲存格加上安全前綴，避免試算表執行內容。匯入詳細資料和資料權限見[正式環境維護文件](OPERATIONS.md)。
